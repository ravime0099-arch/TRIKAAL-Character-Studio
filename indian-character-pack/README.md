# TRIKAAL Indian Character Pack — Alpha

This folder describes the first Indian styling presets for the browser-based 3D prototype.

Included outfit categories in the app:
- पुरुष: कुर्ता-पायजामा, शेरवानी, धोती-कुर्ता
- महिला: साड़ी, लहंगा-चोली, सलवार-कमीज़
- Styling: skin/hair/eye colors, drape, jewellery, mojari

These are procedural preview shapes, not production-quality garment meshes. Photorealistic faces, detailed Indian clothing, hair cards, jewellery meshes, skeletons, facial blendshapes and animation rigs still need to be added as licensed 3D assets.
